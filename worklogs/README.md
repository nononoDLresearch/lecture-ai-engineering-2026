# 作業ログ

エージェントがこのリポジトリで行った作業を、後から確認・再開できるように記録する。課題の提出内容は `lectures/NN/answer.md` に書き、ここには作業の経緯を残す。第3回の宿題で使う `learning_log/` とは別のもの。

- 第 N 回の作業は `worklogs/NN.md`（例：`worklogs/03.md`）に追記する。
- 回に属さないリポジトリ共通の作業は `worklogs/general.md` に追記する。
- 1 回の作業につき 1 件、日時（日本時間）、依頼・目的、変更内容、確認結果、未完了・次の作業を記録する。途中で中断した場合も、そこまでの結果を記す。
- 事実だけを書き、実行していないテストや操作を完了扱いにしない。API キー、トークン、個人情報などの秘密情報は書かない。
- 新しい記録は末尾に追加し、過去の記録を上書きしない。誤りを直す必要がある場合は訂正を明示する。

記入例：

```markdown
## 2026-11-14 15:30 JST — 第3回のツール追加

- 目的：確認問題を出すツールを実装する。
- 変更：`app/tools.py` に `make_quiz` を追加し、`app/agent.py` に登録。
- 確認：`uv run pytest -q` が成功。LLM を使う確認は未実施。
- 次：`--trace` でツール呼び出しを確認する。
```
